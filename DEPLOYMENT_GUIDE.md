# Profitix HRM CPanel Deployment Guide

### 1. Uploading Files
- Zip the entire project folder **EXCEPT** `node_modules`.
- Upload and extract it to your CPanel root (e.g., `/home/username/profitix-hrm`).
- **Option A (Subfolder)**: If you want it in a subfolder, just leave it there. The .htaccess will handle it.
- **Option B (Domain Root)**: Move everything to `public_html` OR keep it outside and symlink the public folder.

### 2. Database Setup
- Create a new MySQL Database in CPanel.
- Create a Database User and assign it to the database with ALL privileges.
- Go to phpMyAdmin, select your new database, and **Import** `profitix_production.sql`.

### 3. Environment Config
- Open `.env` in CPanel File Manager.
- Update `DB_DATABASE`, `DB_USERNAME`, and `DB_PASSWORD` with your CPanel credentials.
- Set `APP_ENV=production` and `APP_DEBUG=false`.
- Set `APP_URL=https://your-domain.com`.

### 4. Storage Link
- If images or profile photos don't show, run this via Cron Job or SSH:
  `php artisan storage:link`
